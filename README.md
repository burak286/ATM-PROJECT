# 🏧 ATM-PROJECT (C++)

Bu proje, **Bilgisayar Programcılığı 1. Sınıf** eğitimim sürecinde C++ dilinde öğrendiğim temel ve orta düzey programlama konseptlerini pratik etmek ve uygulamak amacıyla kişisel olarak geliştirdiğim **terminal tabanlı (CLI) bir ATM simülasyonu** projesidir.

---

## 🚀 Öne Çıkan Özellikler

* 🔐 **Kullanıcı Girişi ve Güvenlik:** PIN / Şifre doğrulamalı oturum yönetimi.
* 💰 **Bakiye Sorgulama:** Anlık hesap bakiyesini görüntüleme.
* 💵 **Para Yatırma:** Hesaba bakiye ekleme işlemleri.
* 💸 **Para Çekme:** Bakiye kontrolü yapılarak hesaptan para çekme.
* 📜 **İşlem Geçmişi (Logs):** Yapılan finansal hareketlerin takibi ve listelenmesi.
* 🚪 **Güvenli Çıkış:** Oturumu güvenli bir şekilde kapatma.

---

## 🛠️ Kullanılan Teknolojiler ve Konseptler

* **Dil:** C++
* **Arayüz:** Terminal / Command Line Interface (CLI)
* **Uygulanan Programlama Konseptleri:**
  * Nesne Yönelimli Programlama (OOP) - Sınıflar, Nesneler ve Kapsülleme (Encapsulation)
  * Kontrol Yapıları (`if-else`, `switch-case`)
  * Döngüler (`while`, `for`)
  * Fonksiyonlar ve Modüler Kod Yapısı
  * Kullanıcı Girdisi Doğrulama (Input Validation)
